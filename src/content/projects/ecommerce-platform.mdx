## 项目概述

这是一个功能完整的电商平台，提供从浏览到支付的全流程购物体验。

## 核心功能

- 用户认证与权限管理
- 商品分类与搜索
- 购物车管理
- 订单处理系统
- Stripe 支付集成

## 技术亮点

使用 Next.js 14 的 App Router 构建，采用 Server Components 提升性能。
