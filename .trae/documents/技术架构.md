# 技术架构文档

## 1. 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                      静态页面 (SSG)                      │
├─────────────────────────────────────────────────────────┤
│  src/                                                   │
│  ├── components/        # 可复用组件                      │
│  │   ├── layout/       # 布局组件 (Header, Footer)       │
│  │   └── ui/           # UI组件 (Card, Button, Tag)     │
│  ├── content/          # Content Collections             │
│  │   ├── config.ts     # Schema定义                      │
│  │   ├── projects/     # 项目MDX文件                     │
│  │   └── blog/         # 博客MD文件                      │
│  ├── layouts/          # 页面布局                        │
│  ├── pages/            # 路由页面                        │
│  │   ├── index.astro   # 首页                            │
│  │   ├── about.astro   # 关于页                          │
│  │   ├── work/         # 作品集                          │
│  │   └── blog/         # 博客                            │
│  └── styles/           # 全局样式                        │
├─────────────────────────────────────────────────────────┤
│  配置文件                                                │
│  ├── astro.config.mjs  # Astro配置                       │
│  ├── tailwind.config.js # Tailwind配置                   │
│  └── tsconfig.json     # TypeScript配置                  │
└─────────────────────────────────────────────────────────┘
```

## 2. 技术栈详情

| 技术 | 版本 | 用途 |
|------|------|------|
| Astro | ^5.0 | 静态站点生成框架 |
| Tailwind CSS | ^4.0 | 原子化CSS框架 |
| @astrojs/mdx | ^4.0 | MDX支持 |
| @astrojs/tailwind | ^6.0 | Astro Tailwind集成 |
| @astrojs/sitemap | ^4.0 | SEO sitemap |

## 3. 路由定义

| 路由 | 文件 | 描述 |
|------|------|------|
| `/` | `pages/index.astro` | 首页 |
| `/work` | `pages/work/index.astro` | 作品集列表 |
| `/work/[slug]` | `pages/work/[slug].astro` | 项目详情 |
| `/blog` | `pages/blog/index.astro` | 博客列表 |
| `/blog/[slug]` | `pages/blog/[slug].astro` | 文章详情 |
| `/about` | `pages/about.astro` | 关于页面 |

## 4. Content Collections Schema

### 4.1 Projects Schema
```typescript
const projects = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    excerpt: z.string(),
    tags: z.array(z.string()),
    coverImage: z.string(),
    githubUrl: z.string().optional(),
    liveUrl: z.string().optional(),
    publishedAt: z.date(),
    featured: z.boolean().default(false),
  }),
});
```

### 4.2 Blog Schema
```typescript
const blog = defineCollection({
  type: 'content',
  schema: z.object({
    title: z.string(),
    description: z.string(),
    publishDate: z.date(),
    tags: z.array(z.string()),
    author: z.string().default('Author'),
    draft: z.boolean().default(false),
  }),
});
```
